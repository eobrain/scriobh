Over the years I have tried many different technologies for self-hosting my blog, currently at http://eamonn.org.

Up till now I have used either a fully-dynamic online database-driven architecture, or static site generated by an offline site generator.  But now, in this blog I'm using a fully-static online architecture. 

|Fully Dynamic Online|Offline Generation of Static Content|Fully Static Online|
|----|----|---|
| ![dynamic CMS and content][1] | ![manual CMS, content static][2] | ![CMS static, content static][3] |
| An online database-driven CMS[^4] provides both an editing interface and the the presentation of the blog to the end user. | An offline site-generator takes the content from the writer and generates the blog content for distribution via a CDN[^5]. | A fully-static web app distributed via a CDN provides an in-browser editing interface which securely updates Github, from which static content is synced to the CDN  |

[^4]: content management system
[^5]: content distribution network

When I started blogging the only self-hosted solutions were full-dynamic PHP-based systems like Wordpress. The lack of scalability and hassle of maintaining a server and dealing with the never-ending security vulnerabilites of PHP made this less and less attractive, and so as soon as idea of static-generation sites emerged I moved to that.
